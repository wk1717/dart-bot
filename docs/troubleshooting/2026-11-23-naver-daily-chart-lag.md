# 현재가가 10초마다 갱신돼도 안 바뀜

- 발생: 2026-11-23
- 관련: 네이버 `fchart.stock.naver.com` 일봉, `polling.finance.naver.com` 실시간 시세, `app.py` 모의투자 탭
- 상태: 수정 완료 (c8773e9)

## 증상

모의투자 탭에 `st.fragment(run_every="10s")`로 10초 자동 갱신을 넣었는데, 장중에 가만히 두어도 현재가와 수익률이 안 바뀜.

## 배경

현재가는 일봉 차트 API의 "오늘 종가"를 장중 현재가로 쓰고 있었음 (`fetch_chart(code, 1)[-1][4]`). 과거 주가 수집에 이미 쓰던 API라 그대로 씀.

## 원인

가격 소스를 10초 간격으로 찍음. 삼성전자(005930)는 거래가 많아 거래량이 계속 늘어야 정상.

```
10:52:30 chart ['175800', '8635800'] realtime [('005930', '175,700', '8,642,558'), ...]
10:52:40 chart ['175800', '8635800'] realtime [('005930', '175,800', '8,643,659'), ...]
10:52:50 chart ['175800', '8635800'] realtime [('005930', '175,700', '8,645,533'), ...]
```

일봉 차트는 30초 동안 가격·누적거래량이 그대로고, 네이버 증권 화면이 쓰는 실시간 API는 계속 바뀜. 일봉 API가 장중 값을 늦게 갱신하는 게 원인.

## 해결

현재가만 실시간 API로 바꿈. 과거 주가 수집과 거래일 계산은 일봉 그대로 씀 (종가 확정 뒤라 문제없음).

```python
def fetch_now(codes):
    url = "https://polling.finance.naver.com/api/realtime/domestic/stock/" + ",".join(codes)
    ...
    return {d["itemCode"]: int(d["closePrice"].replace(",", "")) for d in json.load(r)["datas"]}
```

- 여러 종목을 쉼표로 한 번에 받음 → 보유 종목 수와 상관없이 10초에 요청 1번
- `closePrice`가 "175,700" 같은 문자열이라 쉼표 제거
- 비공식 API라 막히면 현재가만 비우고 표는 그대로 보여줌

## 수치

| | before (일봉) | after (실시간) |
|---|---|---|
| 30초 동안 삼성전자 누적거래량 변화 | 0 (8,635,800 고정) | 8,642,558 → 8,645,533 |
| 화면 현재가 | 안 바뀜 | 10초마다 바뀌는 것 브라우저에서 확인 |

측정: 위 로그는 두 API를 10초 간격으로 3번 같이 호출해서 찍음 (11/23 장중).
